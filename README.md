# Join – Project Management Web App

**Join** is a team-developed web application created as part of the *Developer Academy* program. 
It is designed as a project management tool that helps visualize tasks, assigned responsibilities, and current progress within a team. 
The goal is to support an organized and collaborative workflow.

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase
- Git / GitHub

## Features

- Create, edit, and delete tasks
- Assign team members to tasks
- Visualize task status (e.g. To Do / In Progress / Done)
- User-friendly board overview for all tasks
- Cloud data handling via Firebase
